# 研究笔记

本目录存放与公地引擎相关的研究材料。

## 建议的研究方向

### 法律与合规
- 平台合作社在中国的法律实体选择（合作社法人、社会企业、有限合伙）
- 网约车、即时配送、支付等行业的牌照要求
- AGPL-3.0 在中国法律下的可执行性
- 劳动者在合作社模式下的劳动关系认定

### 经济学
- 各行业的抽成机制拆解（外卖、网约车、家政）
- 无补贴模式下的单位经济模型
- 合作社 vs 资本平台的全成本对比

### 治理
- 多利益相关方合作社的投票与决策效率
- 民主治理与平台迭代速度的平衡
- 跨合作社联邦的协调机制

### 社会学
- 劳动者对平台合作社的接受度调研
- 平台劳动者的组织化程度与组织方式
