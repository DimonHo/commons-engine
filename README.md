# 公地引擎 · Commons Engine

[![CI](https://github.com/DimonHo/commons-engine/actions/workflows/ci.yml/badge.svg)](https://github.com/DimonHo/commons-engine/actions/workflows/ci.yml)
[![license](https://img.shields.io/badge/code-AGPL--3.0-blue)](./LICENSE)

> **用技术夺回被资本垄断的平台。**
> 一个开源的公地引擎——让劳动者自己的合作社，而非资本平台，来运营打车、外卖、本地生活等平台经济。

公地引擎是一套**开源共享基础设施**，支撑各类平台合作社（Platform Cooperative）的运行。它把供需匹配、支付分账、信用评价、纠纷仲裁、调度算法、合作社治理等通用能力，做成开源协议与开源代码，归全社会公有。

任何劳动者合作社都可以 fork 这套引擎，在自己的城市、自己的行业里运营一个实例——骑手是股东，司机是股东，利润按劳动贡献分红，而非按资本分红。

---

## 为什么需要公地引擎？

今天的互联网平台被资本裹挟：网络效应形成垄断，算法黑箱剥夺劳动者的议价权，烧钱抢地盘再收割的模式把劳动者和消费者剩余一起榨干。外卖抽成 25-30%、网约车抽成 20-30%——这不是"老板心黑"，是所有权和治理结构数学上的必然结果。

**仅仅做一家"有良心的平台公司"会失败**，因为它照样要面对资本逻辑：融资 → 垄断 → 收割，最后被结构吃掉。

公地引擎建一个全国统一的大平台——和美团、滴滴一样大，用户体验也一样好。唯一的区别：这个平台不归资本股东，归全体成员共有。平台这件事不该是私人摇钱树，而该是公共基础设施。

## 架构：全国单一平台 + 渐进式联邦

公地引擎是**全国统一的单一平台**——一个劳动者 App、一个消费者 App、一个统一后端，用户体验与美团/滴滴完全一样。区别只有一个：**这个平台归全体成员共有，不归资本股东。**

```
┌─────────────────────────────────────────────────────────┐
│              全国统一的 App（劳动者端 + 消费者端）          │
│              开源代码 · AGPL-3.0 · 基金会守护              │
└───────────────────────────┬─────────────────────────────┘
                            │
             ┌──────────────┼──────────────┐
             ▼              ▼              ▼
        华北节点         华东节点        华南节点  ...
       （规模化后按区域拆分后端，App 始终统一）
             │              │              │
             └──────────────┼──────────────┘
                            ▼
            ┌───────────────────────────────┐
            │     平台合作社（全员共有）      │
            │  劳动者 40% · 用户 30% · 社区 30%│
            │  利润按劳动分配 · 治理民主透明   │
            └───────────────────────────────┘
```

- **统一体验**：用户只有一个 App，跨城市无感使用。
- **渐进式联邦**：起步单一中心化部署，规模化后按区域拆分后端节点（降低单点风险、满足属地合规），但治理权始终属于全体成员。
- **全员所有制**：平台是一个合作社法人，劳动者、用户、社区代表各有法定投票权重，利润按劳动贡献分配，不可被收购。

## 为什么是现在？

AI 时代第一次让"非烧钱模式"有可能在成本上和资本平台正面竞争：
- AI 把工程人力压缩一个数量级（1 个工程师 + AI ≈ 过去 10 人的产出）
- 客服、审核、调度、地推的边际成本被 AI 大幅压低
- 开源基础设施已经成熟（支付、地图、IM、调度算法均有成熟开源件）

**我们不需要烧 100 亿，因为我们用 AI + 开源把运营成本压到了原来的十分之一。**

## 如何参与

公地引擎需要四类贡献者：

- **技术人**（工程师 / 设计师 / 产品 / 数据）：贡献公地层代码与设计，你的每一行代码跨所有行业、所有城市复用。
- **劳动者**（骑手 / 司机 / 家政工 / 配送员）：第一手的需求与痛点，你们是平台的真正主人。
- **研究者**（法学 / 经济学 / 社会学 / 公共政策）：合作社法律结构、治理设计、政策空间研究。
- **组织者**（工会 / 社区工作者 / NGO）：本地合作社的组建与运营落地。

详见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

## 开源协议

- **代码**：GNU AGPL-3.0（网络服务条款防止资本 fork 后闭源收割）
- **文档**：CC BY-SA 4.0

选择 AGPL 是刻意的：任何人可以自由使用和修改，但如果有人提供网络服务使用了修改后的代码，**必须公开其修改**。这从法律上防止资本拿走我们的公地、闭源后再收割。

## 快速启动

```bash
# 1. 克隆仓库
git clone git@github.com:DimonHo/commons-engine.git
cd commons-engine

# 2. 启动基础设施（PostgreSQL + PostGIS + Redis）
docker compose -f deployments/docker-compose.yml up -d

# 3. 构建并运行
./gradlew bootRun

# 4. 冒烟测试（另一个终端）
bash deployments/smoke-test.sh
```

冒烟测试验证全链路：注册消费者+劳动者 → 位置上报 → 自动匹配 → 健康检查。

开发时使用 H2 内存数据库（`-Dspring.profiles.active=test`），无需 Docker。
